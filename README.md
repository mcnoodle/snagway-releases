# Snagway releases

Installers for [Snagway](https://github.com/mcnoodle/snagway) are published here, and installed
copies of Snagway check this repository's releases for updates. The application's source is not in
this repository.

- **Download**: open [Releases](../../releases) and pick the latest one: `Snagway Setup x.y.z.exe`
  for Windows, `Snagway-x.y.z-arm64.dmg` for Macs with Apple silicon.
- **FFmpeg source**: Snagway ships FFmpeg 7.1 and FFprobe, which are licensed under the GNU GPL
  version 3 or later. Every release carries the FFmpeg source archive (`ffmpeg-7.1.tar.xz`, with its
  signature) beside the installers; the licence, the builds and a written offer are in
  `THIRD_PARTY_NOTICES.txt` inside the app.
- **Ask for source or report a licence problem**: open an
  [issue](../../issues/new?title=FFmpeg%20source%20request) here.
